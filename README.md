
# 🚍 Transport Management System

## 📌 Project Description

The **Transport Management System** is a web-based application developed using HTML, CSS, and JavaScript. It helps users explore transportation services, search for popular routes, and book their journeys through a simple and user-friendly website.

The system provides information about bus transport, taxi services, goods transport, and railway transport.

## 🎯 Objectives

* To develop a user-friendly transport website.
* To display different transportation services.
* To provide popular route information.
* To allow users to search for routes.
* To provide a journey booking form.
* To display booking confirmation messages.
* To create a responsive website for desktop and mobile devices.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Route searching and booking form interactions
* **Visual Studio Code** – Code editor
* **Live Server** – Local website preview

## ✨ Features

### 1. Home Page

Displays the website name, introduction, and a button to book a journey.

### 2. Transportation Services

Provides information about:

* Bus Transport
* Taxi Service
* Goods Transport
* Rail Transport

### 3. Popular Routes

Displays sample routes, distances, and estimated travel durations.

### 4. Route Search

Allows users to search for routes by entering a city or route name.

### 5. Journey Booking

Users can enter:

* Passenger Name
* Email Address
* Phone Number
* Starting Location
* Destination
* Travel Date
* Number of Passengers
* Transport Type

### 6. Booking Confirmation

Displays a confirmation message after the user submits the booking form.

### 7. Responsive Design

Adjusts the website layout for different screen sizes.

## 🚀 How to Run the Project

1. Create a folder named `TransportWebsite`.
2. Create the files `index.html`, `style.css`, and `script.js`.
3. Copy the corresponding code into each file.
4. Open the folder in Visual Studio Code.
5. Install the Live Server extension if it is not already installed.
6. Right-click `index.html`.
7. Select **Open with Live Server**.
8. The website will open in your browser.

## 🧭 How to Use

1. Open the Transport Management System website.
2. Explore the available transportation services.
3. Search for a popular route.
4. Click **Select Route** to fill in the journey locations.
5. Enter passenger details in the booking form.
6. Select the travel date and transport type.
7. Click **Book Now**.
8. View the booking confirmation message.
